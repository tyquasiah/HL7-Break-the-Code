# HL7 Break the Code

This public repository contains coursework artifacts for the HL7 Break the Code cohort project. Work is organized by week as the project progresses.

## Week 3 – FHIR R5 resources

The Week 3 folder contains:
- `patient.json`: Initial fictional Patient resource (patient-001).
- `observation.json`: Fictional HbA1c Observation (a1c-001), referencing `Patient/patient-001`.
- `updated-patient.json`: Patient resource updated with a second given name.
- `task-3-answers.md`: Explanations for the Week 3 resource inspection questions.

All patient information in this repository is fictional and is used for educational practice only.

## Week 4 – HAPI FHIR R4 server exercise

The Week 4 folder contains:
- `patient.json`: Fictional NyAsia Ashante Hill Patient resource prepared for FHIR R4 and the US Core 6.1.0 Patient profile.
- `server-operations.md`: Record of the reported POST (201), GET (200), and DELETE (200) results, including the server-assigned Patient ID.

The Week 4 server response details in the operations record are based on the results reported during the exercise. Screenshot evidence should be kept and submitted separately as directed by the instructor.

## Week 5 – SMART on FHIR exploration

The Week 5 folder contains:
- `summary.md`: Notes on SMART App Launch, discovery-document endpoints, scopes and patient context, and the SMART App Gallery exploration. It also records Caren mHealth as the additional app explored and notes that screenshots were not retained for that fourth activity.

## Standards note

Week 3 resources use FHIR R5, as specified in the Week 3 project instructions. Later weeks may use different FHIR versions as directed by their task instructions.

## Project evidence

Screenshots required by the instructor should be stored and submitted separately as directed by the course. Do not commit screenshots containing credentials, access tokens, private account details, or real patient information.
